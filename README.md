## O que foi realizado

**O resultado principal desses 2 subprojetos de IC foi o desenvolvimento de código-fonte em Numba & CuPy com integrador de N-body para aglomeração de matéria e comparação do desempenho entre Python Puro e bibliotecas científicas**.

* Prática de uso de repositórios GitHub para trabalho colaborativo, com documentos, código-fonte, etc;
* Estudo de Física de aglomeração de matéria com gravitação de N-corpos (N-body), que é utilizada em simulações de Sistema Solar, nuvens de asteroides, sistemas estelares, formação de galáxias e estruturas em cosmologia;
* Estudo de métodos de integração numérica (integradores, integrators em inglês) em n-body : Euler, Euler-Cromer, etc;
* Aprendizagem de Python científico : [Python](https://www.python.org/) 3.x, [Anaconda Python Distribution](https://www.anaconda.com/), [documento Jupyter Notebook](https://jupyter.org/), [software Jupyter Lab](https://jupyterlab.readthedocs.io/), [Google Colab](https://colab.research.google.com/) com Python, módulos Python como [NumPy](https://numpy.org/), [Matplotlib](https://matplotlib.org/), [pandas](https://pandas.pydata.org/), etc;
* Aprendizagem de módulo Python [Numba](https://numba.pydata.org/) para computação de maior desempenho em single e multi-thread em CPU, bem como em GPU, com **desenvolvimento de código-fonte em Numba com integrador de n-body para CPU** (single thread e multi thread) **e GPU**;
* Aprendizagem de módulo Python [CuPy](https://cupy.dev/) para **desenvolvimento de código-fonte em CuPy com integrador de n-body para GPU**;
* **Comparação de desempenho de cálculos de n-body**, adotando certo integrador, entre diferentes linguagens/módulos de programação :
  * Python puro;
  * NumPy;
  * Numba para CPU, em single e multi-thread;
  * CuPy para GPU;
* **Desenvolvimento de visualização gráfica de n-body em 2D, 3D, sem e com animações**, via módulos Python gráficos como : Matplotlib, Bokeh, Plotly, K3D-Jupyter, SymPy Plotting Backends, etc;
* Uso de módulo Python [pandas](https://pandas.pydata.org/) para leitura de dados de n-corpos, gravação e análise de resultados, etc;
* Aplicação do código-fonte desenvolvido em algumas **simulações de sistemas estelares**.
